# Cypher releases

Installers for [Cypher](https://mycypher.tech), the end-to-end encrypted team workspace. This repository holds no source code.

## Mac

macOS 12 or later, Apple silicon and Intel. Download **`Cypher-mac-universal.dmg`** from the
[latest release](https://github.com/easybandz777/cypher-releases/releases/latest), open it and drag Cypher to Applications.

The app is signed with a Developer ID and notarized by Apple, so it opens without warnings. It does not update itself yet:
download new versions here. Every release lists the SHA-256 checksum of its files (`shasum -a 256 Cypher-mac-universal.dmg`).

## Everywhere else

Cypher also runs in the browser at [mycypher.tech](https://mycypher.tech).
